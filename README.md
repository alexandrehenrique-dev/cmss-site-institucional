# Corporação Musical São Sebastião — Site Institucional

## Visão Geral
Site institucional e cultural da Corporação Musical São Sebastião, com foco em tradição, memória histórica, atuação social e divulgação institucional.

## Estado do Projeto
MVP em fase inicial.
Atualmente o repositório contém apenas protótipos visuais validados que servirão como base para implementação do frontend.

## Estrutura do Repositório
- /prototipo — Protótipos visuais (desktop e mobile, light e dark)
- /frontend — (a ser criado) Código do site em Next.js

## Decisões Técnicas
- Framework: Next.js
- Estratégia de renderização: Static Site Generation (SSG)
- Conteúdo: Arquivos JSON versionados
- Abordagem: Mobile First
- SEO e acessibilidade como requisitos obrigatórios

## Princípio Fundamental
Conteúdo é configurável via JSON.  
Estrutura e layout são definidos em código.

## Fora do Escopo Atual
- Backend funcional
- CMS com painel administrativo
- Autenticação
- Galeria dinâmica

## Observação
Este projeto prioriza clareza, estabilidade e respeito à identidade cultural da instituição.
